# Trusted local private recording session plan

**Goal:** 在不经过宿主聊天或模型的可信本地窗口内连续提交多条私密文本，各条独立加密并关联同一会话。

**Constraints:** 单次窗口至多 100 条；此为本地资源限制，不是服务端持久会话配额。重开后的相同内容由可信用户负责重新输入，系统无法证明先前未写入的内容。窗口不处理流、附件或模型对话；保留既有回执、权限、取消和日用门禁。仅返回无正文的会话编号、已确认条数及待确认事件编号；中断时不得宣称回滚。

1. 扩展单条采集的可选序号，默认行为兼容；实现带并发保护、逐条唯一编号、相同正文重试和关闭后结果不确定的会话状态。
2. 实现单独的可信本地窗口与显式 CLI 入口；每次成功后清空输入，不展示既往明文；重开可携带未确认事件编号和序号。
3. 使用合成数据验证并发、关闭、失败重试、会话上限、Tk 控件、服务加密和普通读／搜索隔离；验证独立安装包、类型检查和安全审查，再按票提交。
