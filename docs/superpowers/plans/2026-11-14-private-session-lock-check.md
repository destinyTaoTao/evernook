# Private window session-state safeguard

**Goal:** 在既有输入桌面检查之外，要求当前 Windows 会话处于活动且未锁状态；无法确认时拒绝或关闭私密窗口。

1. 使用 Windows WTS 当前会话信息，核对结构版本、进程所属 session ID、连接状态与锁定标志；查询失败、数据截断、未知状态及不支持的旧系统均拒绝。
2. 三个本地私密输入／显示窗口在打开和轮询时使用同一检查；提交前再检查，不改变私密 SDK 的既有调用契约。
3. 用合成 API 结果验证锁定、断连、错误、缓冲长度和资源释放；隐藏 Tk 测试验证关闭与清空。只读核对当前会话 API，不主动锁屏或中断用户桌面。
4. 独立审查和安装包回归后提交；明确轮询可能漏过短暂状态变化、无物理本人保证，真实锁屏和日用门禁仍待验收。
