# Private capture explicit gaps

**Goal:** 为可信 SDK／CLI 显式报告私密材料不能保存或发送结果未知，避免误认为全量保存。

1. 本地预检显式敏感 Capture，遇流、附件、缺失／不完整输入、工具元数据或预取消时不调用传输，返回固定非秘密缺口和 `not_submitted`。
2. 只有完整文本走既有加密操作；确认双库关联后返回 `saved`，请求开始后任何传输、加密或回执问题均返回 `outcome_unknown`，保留同一来源重试要求。
3. 可信 CLI 仅从 stdin 接收 JSON；从不回显内容，记录客户端序列化与非支持材料边界；测试真实服务、加密失败、取消竞争、敏感哨兵、无普通回退和原接口兼容。
4. 源码与安装包测试、类型检查、独立安全审查通过后提交；注明这不是流／附件加密存储或 #115 全部验收。
