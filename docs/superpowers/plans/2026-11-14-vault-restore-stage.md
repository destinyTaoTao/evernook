# 保险库离线恢复暂存（#214）

目标是将 #213 的单收件箱备份恢复到新的私有暂存容器，验证独立备份恢复材料、保险库口令和所有对象，并与已恢复的普通账本逐项核对。此阶段不接回服务、不改变缺失保险库状态或日用门禁。

1. 可信本地入口确认服务未运行，取得现有服务锁和账本独占栅栏，复核管理员身份和缺失保险库状态。
2. 校验固定文件集、签名及加密流；在私有临时目录解密保险库材料，禁止覆盖、路径嵌套和秘密出现在命令行或输出。
3. 在栅栏下制作普通账本私有检查副本，只在副本中移除缺失状态，使用既有保险库校验逻辑逐条解密、检查签名及关联，并核对备份绑定。临时副本可能含普通明文，强杀后可能残留。
4. 全部通过后原子发布新容器；不信任作为未来接回授权的历史验证结果，接回时必须重新验证并处理期间变更。
5. 用合成数据测试正确恢复、错误密钥与口令、篡改、账本不匹配、权限、运行中服务、取消、故障及无覆盖，检查安装包和类型；独立安全审查后再提交。
