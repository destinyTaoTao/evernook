# dsh private recording session integration

**Goal:** 从 dsh 管理页面显式启动可信本地连续私密记录窗口，网页和宿主只处理受限的非秘密状态。

1. 新增固定命令启动与严格回执校验；保存成功、取消、带编号的未知结果和无编号的崩溃未知结果独立处理。崩溃后不编造重试编号。
2. 保持默认关闭、本机来源与 CSRF 检查；单条和连续窗口相互排斥，不允许未知结果被隐式丢弃。
3. 页面提供启动、状态、可用时重试和明确放弃；说明输入只在本机、不发送模型，修正旧提示对跨重启重试可验证性的过度表述。
4. 使用模拟子进程和隔离服务验证互斥、字段拒绝、崩溃、回执边界与 CSRF；构建安装包并做独立安全审查，保留真实浏览器、锁屏和日用门禁。
