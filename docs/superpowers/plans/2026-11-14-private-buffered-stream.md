# Private buffered text stream plan

**Goal:** 安全保存完整缓冲私密文本流的拼接原文，并明确原分块和时间信息未归档。

1. 仅在无附件／工具元数据、原文本为空、输出完整时接受最多 4096 个字符串片段，逐片检查 UTF-8 与总 1 MiB 上限；不合格时不发送。
2. 在可信进程内拼接后复用现有加密事件、来源幂等、授权和回执校验；无论成功与否，明确告知分块边界未保存。其他材料保持 #222 的显式缺口。
3. 合成测试覆盖准确解密、普通存储泄露、取消、无效编码、大小上限、同源重试及冲突、CLI/SDK、安装包和安全复核；不宣称实时流或附件支持。
