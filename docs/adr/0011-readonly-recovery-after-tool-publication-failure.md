# 工具发布失败后先恢复为只读续接

用户确认首版保留失败会话锁定，经可信页面核对后创建禁止工具执行的续接会话，先恢复证据阅读和讨论。核对不代表确认工具成功，也不补造结果；缺少完整保存回执时，副作用仍为未知。恢复本身不调用模型或工具，再次执行需另行明确授权，首版不提供解禁入口。

替代方案是在原会话自动补结果并继续执行，或首版同时建设逐次工具批准。前者不能排除已经发生的副作用被模型换个调用身份重做；后者扩大授权与恢复协议。只读限制必须跨重启持续有效，并由独立宿主执行，不能仅依靠提示词或可卸载的页面插件。旧证据保留，新会话引用经状态校验的来源，不把未保存的原生日志内容复制到普通记忆。
