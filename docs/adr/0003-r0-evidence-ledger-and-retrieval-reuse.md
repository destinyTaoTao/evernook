# 原文账本独立保全，检索组件按验证结果复用

根据 [T01](../reports/r0-dsh-2026-10-29.md) 与 [T02](../reports/r0-core-2026-10-29.md) 的实测，建议由小型本地账本负责原文、幂等回执及后续更正/抑制契约，再评估复用成熟检索组件；暂不将 MemOS `2.0.16-beta.1` 原样作为唯一权威证据账本。其内核有可运行的多路检索与维护能力，但长原文的公开回取、原地修订、抑制语义及 dsh 版本范围仍需适配；最小自建原型也缺少完整事实时间语义和无答案控制，不能因小样本命中较高就认定全面胜出。

代价是自行维护可靠底座与宿主适配；收益是原始证据不受派生记忆组件的裁剪和修订语义支配。此为供 T04 确认的建议，不冻结 Python/TypeScript、embedding、抽取模型、目标平台或恢复策略，也不授权进入 R1；两份已接受 ADR 的共享身份与凭证边界保持有效。
