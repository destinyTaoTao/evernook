# 首期记忆管理界面嵌入 dsh

2026-11-07 确认：优先将已有适配收敛为 dsh 插件，提供独立的 EverNook 一级页面和会话侧栏；首期不另建脱离 dsh 的管理应用。页面复用同一记忆核心与权威证据账本，避免为可视化新增另一份权威记忆或首期独立服务的部署与鉴权成本。

第一版不仅展示画像、兴趣与时间线，还包含查看来源、更正、停止召回及草案审查。物理删除和恢复暂保留既有可信维护入口，待页面的范围预览、确认与残留说明完整后再接入。

交付分两阶段：先在隔离 profile 完成可安装预览版，明确展示支持范围、缺口和降级状态；再补齐正常编程工具工作流所需的可靠采集、流式与恢复保证，并通过质量、性能和安装验收。预览版完成不自动解除 #81/#82 等日用准入限制。实施跟踪见 [Spec #88](https://github.com/destinyTaoTao/evernook/issues/88)。

本决定仅确认交付形态与功能范围，不表示已经实现或验收。页面确认、停止召回粒度与草案拒绝边界已在 [ADR-0010](0010-explicit-user-control-of-memory.md) 收敛；现有权限隔离、原始证据不可改写、离线处理和可靠流式日用门槛继续适用。
