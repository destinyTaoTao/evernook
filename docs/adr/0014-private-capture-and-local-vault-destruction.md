# 用户可主动标记私密，紧急销毁限本机保险库

2026-11-12 确认，用户可以在输入前将整段会话或一条记录标为私密，即使内容没有凭证格式。锁定时允许加密保存；普通搜索、画像与宿主提示均不可取得正文，明文读取沿用独立主口令和逐次授权。已经输入普通宿主的内容可能已有宿主副本，私密入口须在首次交付宿主前生效。

紧急销毁助记词只在可信本地入口输入，首版作用域为本设备的保险库。普通记忆继续保留，独立备份与先前交付的副本分别披露。锁定后还能解锁，销毁成功后本机留存材料应不足以解密；产品实现须分别验证这两种结果。此决定本身不提供密钥销毁或擦除保证。

用户选择可选异机恢复。原设备完全丢失时，用户可用另存的加密备份和独立恢复材料，在新机恢复普通记忆以及明确选入备份的保险库。本机紧急销毁之后，独立备份仍能恢复到其持有的版本。恢复只能证明其掌握的控制记录；来源机器消失后，备份之后的更正、撤销或删除无法从旧副本推知。

仅有旧备份时，先进入审查，列明最后可证时间和缺失的后续控制。用户可在可信入口一次确认，将整份普通备份中按已知控制可见的内容重新开放。已有抑制和撤销继续有效，保险库解锁与新机客户端配对分别办理。
