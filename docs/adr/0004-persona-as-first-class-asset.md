# 核心人设收编为记忆模块一等资产

此前边界是"人设归宿主，EverNook 只承诺不自动改写"；用户确认虚拟伴侣场景下人设的设定与持续进化正是记忆系统的职责，因此核心人设升级为 EverNook 内版本化的一等资产：用户经本地 CLI/界面设定，AI 经人设进化草案提议修改，合入必须用户确认，适配器负责把人设注入各入口。人设分块管理，每块独立版本与草案目标，保留整体快照可回滚。

被否掉的替代是继续把人设留在宿主侧：那样"持续进化"没有可版本化、可回滚的落点，跨外壳也会分叉。代价是人设成为与事实、经验同级的新资产，接纳、更正、注入预算与删除传播都要覆盖它；三档沉淀自动化（全自动/草案审查/手动）对事实、经验与人设一律走草案+确认，只有低风险白名单类别可免审查。用户画像同期确认为一等派生资产，复用时态事实机制。普通归纳不得静默改写人设的不变量不变。
