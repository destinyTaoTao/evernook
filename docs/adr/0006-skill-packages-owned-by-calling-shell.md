# 技能包归外壳，记忆只存经验与引用

用户已确认"桌宠学会并沉淀技能、维护 B站/抖音等账号"的场景按"知识进记忆、能力进外壳、凭证进保险库"落地：可执行技能包（说明书+脚本）存放于调用端外壳并版本化，属调用端扩展功能；记忆模块只保存有来源的技能知识（经验草案 `skill_draft`）及其证据，永不存储或执行技能包，也不把经验自动升级为执行规则。

这一选择延续既有不变量（经验记忆不授予工具权限、沉淀白名单永不收编技能），代价有三：技能包与经验的来源关系只能由调用端记录回链（experience_id），账本内没有一等引用字段——待首个真实技能域验证后再评估是否升级；包格式（SKILL.md+脚本目录）与隔离验收归外壳扩展体系，记忆契约不为其背书；平台对接的合规红线（仅官方 API 或人工发布+证据回流）约束在调用端，本模块文档须显式声明不为扩展越界行为背书。
