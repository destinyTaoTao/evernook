# 页面维护以明确用户意图和具体目标为边界

2026-11-07 确认：dsh 记忆页面内完成预览、用户确认与结果展示，不要求用户回到聊天手输确认命令。可信操作绑定具体操作和目标版本并保留确认记录；版本变化后重新预览。模型仍只能提议，不能取得维护凭证或自行确认。现有同会话命令确认路径继续保留；页面点击需要新增可信宿主动作契约，不能直接调用现有确认函数或用前端布尔值冒充授权。

页面明确区分“移出画像”和“停止召回来源”：前者停止使用指定画像标签，原文仍可独立检索；后者抑制明确来源及其依赖，执行前展示影响范围。两者都保留原始档案，不承诺屏蔽其他独立来源或全库同义表达。此取舍避免用户撤下一个标签时无意影响同源的其他信息，也避免将隐藏标签误认为已经停止召回原话。

拒绝草案后，同一来源版本的同一候选不因重启、补跑或处理器/模型升级重复弹出；用户可以主动重新审查，新证据允许形成新草案，但不能借此自动恢复已拒绝的旧决定。拒绝本身不抑制原话。该拒绝语义需要跨处理器版本的持久控制与回归，现有候选运行幂等不能代替此保证。

以上为已确认设计，不是已实现能力；不改变离线处理、来源校验、并发版本检查、可靠保存及日用准入要求。
