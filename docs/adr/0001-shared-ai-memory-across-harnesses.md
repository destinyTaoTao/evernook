# 多个入口延续同一个 AI 的共享记忆

用户已确认 dsh、pi、桌宠等入口代表同一个 AI，默认共享全部记忆，由独立的本地记忆服务提供；入口、项目、会话分支保留为来源和相关性信息。选择共享有利于连续培养与跨会话延续，同时意味着入口可能召回其他场景的私密经历，调用端需要自行控制记忆出机与模型使用。

曾考虑按 AI 身份、入口和项目隔离后授权共享，用户明确选择全部共享；后续实现不能默默恢复为入口隔离。此决策不授权记忆服务改变核心人设、自动启用执行规则或执行外部动作，也不代表全文档技术选型已经确认。

后续凭证需求见 [ADR-0002](0002-protected-credentials-outside-normal-recall.md)：默认共享适用于普通记忆及脱敏投影，凭证明文需要独立身份验证和逐次授权。
