# 记忆维护的生命周期独立于宿主

2026-11-12 确认，同一台设备上的已配对入口共享一个独立运行的 EverNook 记忆进程。即使 dsh 完全退出，该进程也按本机预算继续索引和沉淀，用户仍能暂停维护。这样，新入口接手会话时能取得前一入口留下的证据与随后形成的记忆。

现有按宿主启动的 stdio 适配器和宿主触发的维护窗口提供可复用实现。用户选择一次完成服务和接口切换，普通数据、可信管理及后台维护在同一切换窗口转入新运行时，避免长期并行维护两条权威写路径。dsh 继续承载聊天、工具和管理页面；进程通信、启动方式与升级切换需独立验收。本决定描述目标部署形态。
