Python3.14.4 / SQLite3.50.4，本机 NTFS 合成目录：`python -m unittest discover -s tests/contracts -p test_maintenance.py -v`，最终 **11 项通过，82.921 秒**。`python -m mypy src tests/contracts/test_maintenance.py` 严格检查 **20 文件通过**。初始 8 项通过65.872秒后，增加扫描途中取消、真实 SQLite trigger 回滚、预算外来源变更三项对抗回归。

已有 CLI 的原文往返/幂等/冲突/索引维护，以及敏感回执/错误不泄露两项子进程回归通过，61.328秒。

真实子进程用 `os._exit(31)` 在领取任务后退出；数据库保留 running/游标，测试将租约推进到过期状态，再由新运行时重领，范围数量与来源不重复。其他用例覆盖跨年漏跑合并与重开、双线程独立运行时并发、暂停后恢复阻止旧 worker、快照后抑制/取消、现有导航读取立刻失效、保留 emoji/组合字符坐标、敏感投影排除、恶意引文与角色扮演不提升、固定失败码重试，以及真实 CLI 子进程。

初次静态检查发现可选 summary 的序列化类型未显式收窄，已用 guarded payload 修复。最终行为测试使用带扫描水位的摘要，以及未摘录来源变更也会失效的版本。

没有执行物理断电、系统睡眠、系统离线、日常宿主空闲调度或性能压测。预算为协作限制，非墙钟保证；CPU占用、生成式摘要/语义主题及原生注入尚未验收。完整支持边界见[导航契约](../contracts/navigation-v1.md)，#18 保持开放。
