## 本轮优化

词法覆盖沿用基线实现。微探针分别得到词法文档复制 1.030、1.026 秒，有效行写入 3.058、3.695 秒。直接聚合扫描单次 8.987 秒，跳过文档复制直接物化有效行单次 10.331 秒，仅调整有效临时表为 `WITHOUT ROWID` 后该项写入单次 2.951 秒。另一次交替比较中，基线词法覆盖为 4.903、4.212 秒，复制后直接计数为 4.981、5.293 秒，使用 CTAS 的单次样本为 5.047 秒。这些变体未提供可重复的整体改进。

语义覆盖与精确向量检索复用已连接的可见性行，去掉逐文档或分块的重复可见性查询。当前嵌入空间没有失败记录时，覆盖证明跳过逐文档失败计数。存在失败记录时仍按当前原文和状态版本核对。只读语义覆盖微探针的两次基线分别为 4.098、4.054 秒，候选为 3.831、3.831 秒。

当调用明确给出两个时间端点且已验证时间索引时，候选先枚举窗口内保留原文的消息 ID，至多读取 2,049 条。窗口至多 2,048 条时，用这份完整 ID 集合约束 FTS 命中，并按原有同一语料库的 BM25 分数、现行原文与版本、可见性和排除规则排序。窗口超出该上限，或缺少已验证的候选索引时，继续走原有前缀和完整回退流程。微探针在窄窗口枚举 514 个 ID，随后生产路径的精确 SQL 为 2.846 秒。只读微探针用于比较 SQL 形状和计划，正式数据以公开接口的交替对照为准。[召回实现](../../src/evernook/semantic.py)

交付代码在冻结测量后补上窄窗口的 ID 类型检查。它在索引预查后验证至多 2,048 个候选 ID，遇到非文本 ID 时继续原有路径。正式样本的 SQL、范围和索引条件与交付代码相同。加入检查后另跑一次同一窄窗口的公开接口，用时 15.460 秒，完整召回页与冻结测量逐项一致。此验证独立于正式 p95。
