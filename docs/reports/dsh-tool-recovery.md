# 失败工具发布的可信核对与只读续接

2026-11-08，实施 [#97](https://github.com/destinyTaoTao/evernook/issues/97)，属于 #94/#88，接续 #95/#96。用户确认首版只创建禁止工具执行的新会话。目标为 Node 24.12.0、Python 3.14.4、Windows 本机 dsh Web 0.2.1-rc.5；使用隔离宿主/profile、合成 provider 和仓库外临时文件，不调用真实聊天模型，不修改日常 profile。

## 实际行为

独立时间线和会话侧栏提供“核对工具发布”。核对器只读原生待决日志，以确定性工具身份回取 Core 原文及完整 capture 回执，不把未保存的原生日志正文复制为证据。调用、原始用户输入、工具报告均可查看来源；结果区分完整回执、保存缺口和未确认，始终保留副作用未知提示。完整工具报告不等于外部状态已独立确认。

owner-only HTTP 沿用 Host/Origin/CSRF、请求大小和生命周期限制。预览绑定原会话事件/头、来源当前状态、内容版本与完整性；Core 独立维护身份持久确认，5分钟有效期、每端64项待确认上限。取消不会撤销已完成操作，过期/变更/其他身份拒绝。模型/MCP没有恢复确认入口。

同一账本记录 `confirmed → complete`，目标会话ID由调用端、核对指纹与来源引用确定。先持久授权，再持久保存目标只读标记，最后提交完成回执；中间失败不谎报成功。重复/并发确认复用目标；完成目标缺失时拒绝自动重建。旧失败会话保持锁定，不补造工具结果、不重新执行旧工具。目标仅保存来源引用与核对元数据；创建动作不运行模型或工具，后续主动讨论才请求 provider。

讨论每次重新读取当前允许的来源，并在最终计数后、provider消费前再核对来源快照；来源失效不会继续发送旧证据。证据以低信任上下文注入，不能成为执行指令。卸载后EverNook不再提供证据注入，但宿主工具禁用仍有效。

## 独立宿主增量

仍只修改 Tools/AgentLoop 两个 JS 产物和既有 scheduler.finish 类型声明；版本、原始/允许的上一版/最终 SHA-256 全部固定。支持由 #95 确切产物升级，其他字节拒绝；升级前须停止独立宿主。启动器验证新哈希，不能混用旧宿主。

Tools 在任何工具执行策略、工具体、前后钩子和内容格式化器前拒绝带只读标记或保留恢复ID的会话。ID先行保护“会话头已创建、标记未追加”的中断窗口。AgentLoop 创建派生会话时读取父会话策略，即使 fork 截在标记之前也继承禁用，第二代同样受限。卸载插件不会移除该宿主限制。首版没有工具解禁入口。
