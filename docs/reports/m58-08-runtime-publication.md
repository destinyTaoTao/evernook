# M58-08：受控运行库发布

Issue #66 增加独立可信 Python 发布入口。它要求经过认证的控制重放归档和独立检查点，在来源写锁期间核对原文范围、重要交代、关键持久版本及维护状态，建立新客户端身份，并在私有新目录保留所需幂等密钥。控制或证据不足时拒绝发布，需要新快照。当前 job 状态从受锁来源同步，防止恢复旧任务状态或漏掉新增控制证据任务。

发布前失败可向原目标重试；发布后回执丢失时，认证发布记录与完整数据库状态验证允许取回同一身份。来源水位变化、目标数据库缺失/回滚/修改、身份材料变化或其他占用目录均拒绝复用。该重试适用于目标尚未使用的窗口；正常审计写入也可能使其失效。

验证：完整契约套件 305 项通过（660.942 秒）；运行中的测试进程使用了启动时的实现快照，最终重试增强另外由恢复专项 8 项通过验证。`mypy src tests/contracts/test_runtime_restore.py` 通过。两路独立审查发现并修复了任务缺口、导航暂停回退、重试空库/回滚、目标重要交代缺失和过期错误吞没，并验证带 FTS 的发布与重试。全量 `mypy src tests` 仍报告 3 个未修改文件中的 5 项既有错误（scopes、persona、consolidation_tiers），本票没有关闭严格检查。

这不是双库同步或全局切主协议；维护端需要停止旧宿主并切换到选定权威运行库。来源不可用、所需密钥材料丢失时仍拒绝。保险库、宿主副本及既有备份不由此恢复或删除。没有测量大库摘要的内存/耗时，也未进行物理掉电和真实宿主切换验收。原 #10 和 #20 不因本增量自动关闭。
