# T06：重要交代逐字回取

日期：2026-10-29。对应 [Issue #7](https://github.com/destinyTaoTao/evernook/issues/7)，基线 `b04d9cc`。[公开行为](../contracts/important-v1.md)在已有受认证本地 Python 边界上增加显式标记和逐字分页回取，不依赖模型或保险库；不增加网络服务、自动执行或全量上下文注入。

## 变更与回归

- 不可变消息的表示/版本/范围引用与重要状态原子提交；标记前核对现存消息、原话与 code point 片段。重复/并发标记返回同 ID 和时间，独立适用标签分别保留；没有复制原文或额外任务。
- 原话在提交后立即可读，重启和数据库边界注入的任务失败不改变标记。默认 2048、上限 4096 code point 分页，绝对范围、下一游标、剩余数明确返回；5009 code point 合成原话分页重组逐字相同。
- 覆盖 emoji、组合字符、CRLF、数字；消息不存在、原文不匹配、错误版本/表示、非法坐标/游标/预算均拒绝；敏感路径只引用既有安全投影，不能从标记绕回未保存原件。所有新增操作复用入口认证/版本检查。
- 存储 v1→v2 事务补表，旧原文/回执/任务保留；握手报告实际支持的能力/存储版本。旧版结构与任务失败由系统数据库边界构造，断言通过公开接口完成。
- 真实子进程在标记 COMMIT 前强制退出后无重要引用，已确认标记后强制退出仍可回取并幂等重试。SQLite 文件由核心关闭；测试故障夹具也显式释放连接。

## 验证

当前 Windows 固定 NTFS、Python 3.14.4、SQLite 3.50.4；复用 checkout 外已安装的开发虚拟环境。完整核心 `python -m unittest discover -s tests/contracts -v`：20 项通过，105.900 秒；`python -m mypy`：严格检查 10 个源码/测试文件通过。耗时包含反复启动 ACL 和子进程，不是服务延迟指标。原始输出保存在 `E:\evernook-lab\r1-important-20261029`，临时数据库和凭证只在 checkout 外。

这不是物理掉电、真实后台抽取、日常运行、备份或 dsh UI 验收。备份目的地、启用、恢复演练按用户决定待办；保险库、模型仍关闭。未推送，未评论/关闭 GitHub 票据，未暂存用户已有设计文件。
