# M58-07：旧归档控制重放

Issue #65 为经认证的旧归档增加独立审查副本重放。可信本地维护端提供来源账本、权限和独立保存的认证检查点；重放核对账本身份、旧证据与控制历史后，应用更正、抑制、撤销、已确认删除及关联事实、画像和经验版本。缺失或分叉时拒绝发布；重复请求仅在来源和检查点一致时复用结果。

输出仍限 `review_required`，不携带普通访问令牌或原账本密钥。覆盖状态需要独立检查点；该检查点只证明取得时所选来源的状态，不能单独证明来源克隆为全局最新。v1 旧归档没有来源认证，仍可审查但不能通过此入口进行认证重放。v2 新归档需要支持 v2 的读取端。控制证据可能包含新原文，普通归档仍未加密。

验证：归档契约测试覆盖后续控制、删除及中断、事实/画像/经验、幂等、身份和历史分叉、检查点回滚、附件分叉、重算公开哈希的篡改；`mypy src tests/contracts/test_archive.py` 通过。完整测试套件在最后一轮证据连续性增强前通过 297 项；增强后重跑了归档契约测试。没有测量规模性能、物理掉电或真实用户数据。正常运行库发布由 #66 单独处理。
