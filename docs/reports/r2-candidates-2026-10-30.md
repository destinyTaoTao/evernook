## 实现与验收映射

| 范围 | 实际交付 |
|---|---|
| 可恢复任务 | 明确来源范围/处理版本的持久化任务、客户端绑定租约、并发领取互斥、过期/失败重领与尝试次数；处理端计算在事务外 |
| 批次幂等与提交 | 同来源版本/处理版本返回同一任务；重复结果幂等，不同结果冲突。候选和成功状态在同一 SQLite FULL 事务内提交 |
| 多来源证据 | 每项候选绑定任务范围内的一或多个原始来源，校验 original/projection、内容/状态版本与 code point 原文片段 |
| 候选/争议边界 | user_statement/assistant_generated 校验原始角色，quoted/roleplay 保留声明标签；所有结果仅 candidate/disputed，不以置信度或合法 JSON 自动接纳事实 |
| 来源失效 | 完成前和读取时核验整个来源快照；任一来源更正/撤销/抑制后整批保守失效，旧候选不可重新进入返回结果 |
| 真实水位 | 输入水位仅本批最大接收时间；完成水位仅有效成功状态可见，与候选提交一致，不宣称连续处理全部历史 |
| 安全与权限 | 复用核心鉴权，租约绑定客户端；令牌仅保存 HMAC 摘要。固定失败码不接收模型异常详情；拒绝敏感候选、越界/错版本来源，保护占位投影不能被补造成事实 |

新派生 v1 表位于同一 SQLite 数据库，核心原文 schema 仍为 v4，不重写既有证据/变更，也不把候选写入普通消息、FTS 或上下文。原始 jobs 仍 pending；没有自动选择、消费或调度。没有增加依赖、MCP 工具、网络端点、模型回调框架或后台进程。

## 保留限制

- 真实离线抽取模型、断网验证、自动语义分类及质量准入尚未实现/验收；未调用真实私有数据。
- 不接纳当前事实，不处理纠错与现实变化、多来源事实合并或历史有效期；来源片段匹配不能证明候选文字含义正确。
- 单批任一输入失效会保守隐藏整个结果，不保留部分来源下的局部候选有效性；不同重叠批次不做全局语义去重。
- 租约使用系统时间，无心跳续期、外部计算取消、自动任务选择、调度或资源抢占；租约丢失须等待过期重领。
- 普通归档保留候选/任务快照但不恢复执行身份；加密备份、最新控制记录完整重放和普通召回恢复继续待办。
- 进程退出与 SQLite 页配额不代表物理掉电/真实磁盘耗尽；规模、时延与长期运行均未验收。
