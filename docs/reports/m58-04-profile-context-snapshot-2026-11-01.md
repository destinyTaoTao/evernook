# M58-04 / #62 画像上下文最终快照

公开 TokenCounter 接口确定性交错：读取画像摘要后、最终检查前提交抑制。旧版本仍交付画像标记，回归在修复前失败。

现在画像携带修订及内容修订，在现有最终同一 SQLite 快照内检查 confirmed 状态、精确修订、来源与确认版本。抑制、更正后重新确认、删除来源或确认消息失效，均移除旧条目并报告 `source_changed_during_context`。删除标签的 `profile_not_found` 不再中断构造。

版本字段进入既有画像及完整 payload 预算；合成预算用例相应调整到仍能放入一条、无法放入两条的额度，没有更改产品默认值。人设独立授权路径未改动。

验证：伴侣上下文 5 项、一般上下文 10 项通过，覆盖上述四种交错及已有事实、经验、原文和预算回归；相关两文件严格 mypy 通过。Standards 0、Spec 0 项确认发现。

检查保证针对最终读取快照；不会撤回已交付 payload，也不把同步 tokenizer 后的任意外部状态变化解释为可撤回。使用合成计数器，不代表真实模型 tokenizer、日常安装、性能或端到端产品验收。
