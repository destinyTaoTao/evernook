# 百万向量的可选 int8 误差界筛选

百万个 384 维合成分块上，一个确实具有语义命中的扰动查询在阈值 0.28 时，从 1,000,000 次合格 float32 距离计算降到 208 次，仍返回相同的全局 18 个和近期 1 个命中，两轮向量阶段分别为 2.11、1.90 秒。较低阈值下筛选会增加额外读取，自动回退的样本最慢为 9.76 秒。

## 原生算分边界

固定个数的 int8 粗排可以遗漏精确命中。例如 `(1,0)` 和 `(1,0.003)` 按共同的方式缩放舍入可产生相同的编码，而原生 float32 cosine 能区分二者。只按粗排取固定个数时，粗分同分可能使精确第一名落在截断线外。上线实现只在证明原始分数低于用户阈值时排除分块。[碰撞、边界与生命周期测试](../../tests/contracts/test_vector_screen.py)

令 `d` 为 1 至 4,096 的维数，`m=max(abs(x))`，`n=||x||₂`。仅对长度、有限性和范数有效且 `0.75≤n≤1.25` 的 float32 输入建立可筛选编码。按 `k=round(127x/m)` 对每维编码，至少一维绝对值为 127。按比例复原后的各维误差至多为半步。用三角不等式归一化，原方向与编码方向的 L2 距离至多为 `√d·m/(127n)`。实现为双精度比例与舍入额外留出 `1e-12`。两个单位方向的内积变化至多为查询与分块的两项半径之和。[计算实现](../../src/evernook/vector_screen.py)

本次仅对锁定的 Windows x64 sqlite-vec 0.1.9 原生实现启用。其两种 cosine 内核均以 float32 累加点积和平方和，再归一化并返回 float32 距离。设单位舍入误差 `u=2⁻²⁴`，取 `g=2du/(1−2du)`。乘加和的绝对误差由 `gΣ|aᵢbᵢ|≤g||a||||b||` 约束，平方和的相对误差至多为 `g`。因此在开方、相乘后，分母的相对误差约束为 `g` 加上末端舍入；点积比值的误差可用 `2g/(1−g)` 加上末端舍入覆盖。原向量范数限定在上述范围，整数编码的最大平方和为 `4096·127²`，量级远离溢出。原向量中次正规分量乘积的绝对误差也远小于双精度留量。实现对两路 cosine 及距离末端舍入累计增加 `64du`。达到或等于保守上界的候选全部保留，由原始 float32 评分决定最终阈值、排序与引用。[固定版本原生内核](https://github.com/asg017/sqlite-vec/blob/v0.1.9/sqlite-vec.c#L436-L469)

## 百万条测量

从前一轮[语义覆盖检查点](2026-11-26-semantic-checkpoint-scale.md)的离线合成库复制普通文件至新建的私有目录。复制前后确认源库 WAL 为空，并校验新旧数据库文件 SHA-256。使用 SDK 公开维护入口构建索引，用时 86.99 秒，主库增长 512,016,384 字节（488.3 MiB）。构建前后公开语义状态相同，原词法检查点有效。本测量使用原有合成指纹，无模型推理。[指纹夹具](../../probes/admission/synthetic_full_vector_scale.py)
