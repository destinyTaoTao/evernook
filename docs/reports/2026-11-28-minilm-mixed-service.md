## 强停和重启

取得最后一份写回执后，发起额外的历史读取，在客户端仍等待时强停本轮独占的服务。此次调用返回 `service_unavailable`。从发出强停到新服务第一次读回并核对原文为 **336.43 毫秒**。随后 120 个新来源逐条核对事件与原始回执，使用原来源重投，120/120 均返回同一份回执。

重启后的公开读取看到 1,000,120 条原文；对已有的 1,000,000 个分块完成精确扫描，扫描未截断、失败分块为零。新增的 120 条原文仍在词法与语义索引队列中。此处验证了已回执写入的持久性；对写进程提交前后的中断以及旧备份恢复另有独立演练。[事务中断和离线恢复](2026-11-28-offline-recovery-drill.md)

## 工作负载与计时

使用 Windows 本机安装的 Core 0.1.99（提交 `74ed38c`）。安装包中 117 份 Python 和 JS 文件与该提交一致，换行符统一后逐文件核对。wheel SHA-256 为 `7f05b4d56534117c48d4a22abd33f807c1e3c5b8a34c4fcf65ad1f65e6b12b18`。开始前，独立回读了百万条 MiniLM 向量，校验每批摘要、64 个重算向量和百万个不同的分词序列。词法和语义索引均已追平。首次服务召回报告 sqlite-vec 0.1.9 精确扫描了 1,000,000 个分块。已开启词法 ID 加速、来源候选索引、词法及语义覆盖检查点。[建库及索引核对](2026-11-28-production-minilm-million.md)

两个独立的 Python 客户端复用各自的连接，用同一个合成身份调用已激活的服务。每轮用屏障同时发起一个 `context` 和一个 `submit_capture`，等两者返回再开始下一轮。写入是一个新来源，读取使用 4,096-token 预算和真实 Qwen tokenizer。读延迟从客户端开始调用到拿到上下文，写延迟到取得持久化回执。解析上下文做验收的耗时排除在外。该窗口测记忆服务，聊天模型生成不计入计时。

查询依次轮换历史编号、近期编号、库内无答案的“外星深海音乐会许可证”和高频词“记录”。每类预热一次，正式样本各 30 次。历史和近期按来源键与原文同时判定命中，无答案另计是否注入了证据。正式窗口内不开后台维护，以便测量“新写入已确认，索引逐渐落后”时的表现。客户端调用区间重叠可由逐轮时间戳核对。p95 用成功返回耗时从小到大排序后第 `ceil(0.95 × n)` 个值，错误与降级单列。该组占冻结准入矩阵的热进程、写入条件；独立用户并发量、持续到达率、空闲/重建条件和冷进程分布需另测。

## 复现

从上面的建库步骤创建全新的隔离副本。先完成向量与分词清单核验，关闭建库程序。在未激活副本上用本机正式配对命令创建本轮专用启动身份。现成夹具若已有对应身份，直接使用。宿主读写使用夹具已有的 `mcp-access-scale-writer.json`。

```powershell
$config = Join-Path $run 'runtime/runtime.json'
$admin = Join-Path $run 'runtime/mcp-access-drill-admin.json'
& $installedPython -m evernook.cli pair --config $config --client-id synthetic-scale-drill-admin --entry synthetic-drill-admin --access $admin --scopes admin,maintain,recall
& $installedPython -I probes/installed/mixed_service_drill.py --config $config --embedding-config $embeddingConfig --context-config $contextConfig --expected 1000000 --rounds 120 --output $newOutput
```

`$embeddingConfig` 指向建库时使用的本地 MiniLM 配置。`$contextConfig` 指向能加载真实 Qwen tokenizer 的上下文配置，本次为 normal 4,096、deep 8,192、pinned 512、7 天和 8,192 字符近期目标，无固定消息 ID。传入全新的输出目录。探针只向专用测试账本写入并重启它启动的服务。若需核对进程树资源，使用项目的 Windows Job 监控器包装第二条命令。[采样与故障注入脚本](../../probes/installed/mixed_service_drill.py)
