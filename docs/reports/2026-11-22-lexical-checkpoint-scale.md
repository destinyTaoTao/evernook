# 百万条词法覆盖检查点实测

在同一份百万条合成来源的两个隔离副本上，使用同一冻结代码进行检查点关闭与启用的平衡 A/B。两侧使用相同的 FTS 消息 ID 格式、词法覆盖加速索引、来源索引和语义向量。

## 夹具与维护

保留夹具的 FTS 为 `CREATE VIRTUAL TABLE "lexical" USING fts5(message_id,terms)`，消息 ID 已索引。本次无需重建 FTS。保留库中旧检查点仍有 16 个对象，内部记录的 SQLite schema 版本为 84，当前为 1，守卫判定已失效。先逐字节复制到外部私有目录。用可信本地 `configure_lexical_checkpoint(enabled=False)` 在副本显式移除这些对象，终态测量将这个已停用的独立库再次复制为两侧夹具。原夹具和用于复制的停用库保持只读。

初次准备中，旧检查点移除耗时 0.451 秒。最终构建前仍有 41,633 个空闲页可供 SQLite 重用。在启用侧通过可信本地 `configure_lexical_checkpoint(enabled=True)` 显式构建最终格式，耗时 71.570 秒，CPU 为 68.844 秒。构建提交后，公开状态为有效，已覆盖 1,000,000 条，待核对队列为空，包含 19 个表、索引和触发器对象。检查点 B-tree 占 41,675 页（162.8 MiB）。复用原检查点腾出的空间后，构建时文件仅新增 176,128 字节。此处区分实际派生结构占用与这份夹具的文件增长。

## 新增、更正、抑制与回退

从关闭侧再复制一个百万库，在新副本显式构建检查点。每个场景调用公开 `MemoryRuntime.search`。实际路径通过监测是否运行全量覆盖查询来确认。对照调用在同一库上强制走全量覆盖路径。11 对完整搜索页逐项一致，包含原文引用、覆盖计数和水位。

| 场景 | 实测结果 |
| --- | --- |
| 新增原文 | 尚未进入 FTS 时仍能命中原文，`pending_messages=1`。可信补索引后变为 ready 并保留相同来源。 |
| 更正 | 旧来源退出召回，尚未进入 FTS 的替换原文可通过待索引路径命中。 |
| 抑制已入索引原文 | 原文仍保留在账本，普通搜索不再返回该来源，当前有效来源覆盖为 ready。 |
| 复制库缺 FTS 行 | 真实原文仍可命中，状态为 behind 且待索引数为 1。补齐后恢复 ready。 |
| 101／102 个待复核 ID | 越过读侧上限后走全量校验，最新的待索引原文仍能命中，准确报告待索引数。 |
| DDL 使守卫失效 | 查询走全量校验。可信维护重建耗时 76.779 秒，原文引用和覆盖页摘要一致，保留 102 条待索引。 |

发布版的生命周期副本首次构建耗时 72.684 秒。验证结束保留 1,000,105 条物理原文，SQLite `quick_check` 返回 `ok`。两次维护耗时各为一次观测，独立于空队列的召回 p95。

独立审查还在小型合成库复现了派生成员标记的对调。总数相同的变更过去可能让尚未索引的原文漏召。当前派生成员写入会登记待复核 ID，搜索在同一快照内重新核对原文和 FTS，维护可整理这些记录。直接改写派生缓存的接收时间会使守卫失效，搜索回退到完整校验。两类故障各有针对性回归。[生命周期探针](../../probes/admission/lexical_checkpoint_lifecycle.py) · [回归测试](../../tests/contracts/test_lexical_checkpoint.py)

## 复现和边界

在隔离合成夹具上确认 FTS 消息 ID 加速、词法覆盖加速及召回候选索引已启用。使用可信维护接口停用旧检查点并复制该状态，再在一个副本上显式准备检查点。保持相同语料和源码，按表中顺序调用公开接口。采集 `_search_coverage` 和实际 `search_state` 返回结果，在关键词回源前记录候选次序，核对三路字面输出及最终完整页。用 SQLite `dbstat` 归属共享数据页并逐字节验证。[规模夹具探针](../../probes/admission/synthetic_full_vector_scale.py) · [词法检查点契约](../contracts/lexical-v1.md#可选覆盖检查点core0113接入候选默认关闭)

性能证据限于本地合成数据、两条固定全范围查询、空待核对队列和一台 Windows 主机。样本数为每臂四次，保留系统缓存。端到端样本 p95 仍高于一秒。

规模和状态变更实测可使用已启用 FTS 消息 ID 格式的原始百万条合成库。生命周期探针只修改新建副本，源库路径和输出目录须在仓库外。
