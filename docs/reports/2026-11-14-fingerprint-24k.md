## 2026-11-22 双标签前后台与迟到的写入回执

在 Windows 11 26200 上，用独立安装的 Core 0.1.97 wheel、`4c57f79` 构建的 preview.64 安装包及验证过的 dsh 0.2.1-rc.5 运行两次。每次用两个隔离的认证页面与一个新建合成账本。Chrome 157.0.8103.79 和 Chromium 145.0.7632.6 的同窗标签由浏览器自身报告 `visible` 和 `hidden`。测试驱动关闭 Playwright 默认的焦点模拟，未注入页面可见性事件。包内 `client.js` 与该提交逐字节一致。

在 A 页通过真实管理路由提交画像移除，等待服务保存第 3 版，暂缓把 HTTP 回执交给页面。切到 B 页后，A 页在收到回执前清除旧画像与确认弹窗，B 页显示提交后的结果。交付迟到回执后，两次后台观测窗分别持续 12.215 和 12.205 秒，A 页均未发出读取或指纹请求。A 页回到前台后发起新的认证读取，旧画像保持移除，界面显示写入成功。两个账本各留存三条合成记录，数据库 `quick_check` 均通过，测试监听端口均释放。另通过两项 Node 页面回归。

早期尝试分别受到驱动模拟焦点、初次预览提示和探针网络包装器影响。最终使用真实原生标签状态，并通过固定回环地址转交那一次确认请求。此结果用于 [#134](https://github.com/destinyTaoTao/evernook/issues/134) 的前后台切换与迟到回执边界。实际系统锁屏、睡眠唤醒和长期多标签负载仍待验收。
