# 百万条 MiniLM 账本的上下文分阶段计时

同一份 Core 0.1.101 安装包上，小积压组的四次完整上下文调用耗时 **15.922–19.773 秒**，其中向量排名 SQL 用了 14.285–14.602 秒。120 条积压后，两个覆盖检查点均回退，每次词法和语义覆盖合计耗时 **15.722–17.001 秒**，高频词的字面搜索还用了 10.633 秒。该组四次调用耗时 **34.151–46.810 秒**。两组每种查询各一次，全部排除在正式 120 轮的延迟分布外。[同版本完整负载与恢复结果](2026-11-28-minilm-mixed-repeat.md)

小积压时，向量排名 SQL 占端到端耗时的 73.0%–89.7%。大积压前后的读取走了不同的覆盖路径。小积压时，词法及语义覆盖各自取到检查点结果；大积压开始前，两套检查点各有 120 个变更标记，超过 0.1.101 读取时最多核对 100 个标记的限制。大积压四次词法覆盖均调用了完整核对，语义覆盖也四次回退。向量排名 SQL 在大积压组仍用了 15.115–16.767 秒。八次样本均走 sqlite-vec 0.1.9 精确检索，各扫描 1,000,000 个分块，失败分块为零、扫描未截断。

高频词的三次字面搜索在小积压时分别耗时 0.118、0.114、2.380 秒，大积压时分别为 3.091、2.837、4.704 秒，顺序为全库词法、全库精确、近期词法。BM25 候选 ID 在两次高频词样本分别用了 0.301、0.321 秒。两组历史、近期编号均返回目标来源与原文，两组无答案查询都未注入证据，八次上下文均报告索引落后，`complete=false`。八次配对写入全部在读区间内完成并取得回执，耗时 21.08–164.34 毫秒。

## 样本来源

两组都使用独立私有账本与进程，wheel SHA-256 为 `0bbde6586ec11652100f8c31bdb2aa798195c534cc8b80554e80370797b3ac3a`。小积压副本起初由已核验且静止的正式夹具逐字节复制，schema cookie 为 69，双检查点、来源候选索引和词法 ID 加速四项均有效。此前独立的 0.1.99 对照在该副本写入四条记录，四次查询向量排名 SQL 为 19.576–21.529 秒；版本和采样时段均不同。0.1.101 测量前重新核对了四项开关、100 万分块与两种队列各 4 条积压，测量再写入四条。八条积压都来自诊断副本。

大积压组取自 0.1.101 正式 120 轮、强停和重放复验结束后的静止副本，未启动后台维护。字节复制后重新核对 SHA-256、schema cookie、来源候选索引、词法 ID 加速及两套检查点的积压数。四条诊断写入仅发生在副本上。小积压四次词法快照各有 5、5、6、8 条待处理，语义快照各有 5、6、7、8 条；大积压分别为 121、121、123、124 和 121、122、123、124。并发写入可能在同一调用的两个读取快照之间提交。

两组均用原合成身份、四种查询、4,096-token 预算、真实 MiniLM 和 Qwen tokenizer。两个独立客户端每轮同时发起一次 `context` 和一次 `submit_capture`，关闭后台维护。0.1.101 先测大积压，再测小积压；两组各自重启服务，均按表的查询顺序执行，首次模型调用包含在各组首条记录中。没有交错试次或清空操作系统文件缓存。读路径和单次阶段成本可从这些样本直接观察；正式 p95 及其逐轮变化仍以完整负载报告为准。

## 计时方法和复现

探针在安装包启动的本地服务进程中使用 Python 3.14 的选择性监控，给实际执行的方法和两个指定代码区间计墙钟时间。客户端从调用真实认证入口开始，计至返回。每个服务阶段同时保留调用次数、含子调用时间和扣除已计时子调用后的独占时间。所有独占时间合计等于 `dispatch`；`outside_dispatch_ms` 为客户端时间减去它的差值，包含传输、调度、回包处理和写诊断记录。并发写入及后台 tokenizer 空串预热都有独立时钟，不能再加进读取耗时。每类各一条，无法从中估算阶段 p95 或反推出以往慢请求的执行轨迹。[逐次时间、调用次数、执行后端和快照](2026-11-28-minilm-context-phases.json)

表内细分阶段互不重叠。向量排名 SQL 包含当前来源资格和版本连接、距离计算、按来源聚合、全局和近期排序、取回 SQL 候选行。材料化选中证据、授权、融合、其他上下文组装和传输可在 JSON 查看；`semantic_candidates`、`recall`、`context_build` 和 `dispatch` 的含子调用时间属于嵌套总量。BM25 时段包括为排序取候选、检验资格和去重；这里未单独测量纯距离计算、纯 BM25 评分、模型内部推理、磁盘 I/O 或 CPU 时间。

复现时，使用完成百万库向量校验并关闭所有连接的专用合成账本。将数据库及存在的 WAL 逐字节复制到新的私有 runtime，校验文件摘要、更新副本配置的 `data_dir`，保留配对身份。参考[百万库校验](2026-11-28-production-minilm-million.md)检查覆盖与有效开关。已配对专用管理员、尚未激活的副本使用以下命令，已激活的专用副本省略 `--activate-owner`。输出目录须不存在。每次诊断会新增四条合成原文。[服务阶段探针](../../probes/installed/mixed_context_phases.py)

```powershell
& $installedPython -I probes/installed/mixed_context_phases.py --config $config --embedding-config $embeddingConfig --context-config $contextConfig --output $newOutput --activate-owner
```
