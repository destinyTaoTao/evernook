# dsh 工具发布屏障：首批实现与验证

日期：2026-11-07。对应 [#95](https://github.com/destinyTaoTao/evernook/issues/95)，属于 [#94](https://github.com/destinyTaoTao/evernook/issues/94)；不关闭 #81/#82 的正式日用门禁。

## 交付边界

独立 Windows Web 宿主固定 dsh 0.2.1-rc.5、Node 24.12.0，插件 preview.11。原版的 `tools/result` 是不等待异步观察者的通知，无法阻止未保存结果返回。本批对 Tools/AgentLoop 两个确切 JS 产物及一处类型声明增加发布屏障 v1。补丁按原始与目标 SHA-256 校验，不修改全局 dsh，不猜测兼容新版本；上游 MIT 声明随补丁保留。

```text
原生调用 → 参数保存 → 工具执行 → 最终转换/冻结
  → await 完整保存回执 → tools/result、会话结果、后续模型
                      ↘ 失败：停止，保留待核对会话
```

插件必须显式配置 `streamMode: buffered` 与 `toolPublication: true`。普通 capture/recall 身份负责保存，管理身份不进入模型。结果快照包含调用/根调用身份、原生序号、最终 DTO 与附加上下文；关联实际用户输入回执，不编造发生时间。原始调用参数、实际执行参数、PTC 调用展示和最终 PTC 日志分别保存并核对。缺原话、敏感分流、超限或不完整回执均不能放行。

PTC 的原始返回值与用于展示的最终日志可能不同，因此两处均需保存屏障；最终日志保存之前，嵌套返回值也不能交给脚本继续使用。并行工具的发布保持模型顺序；嵌套保存失败不能被外层工具吞掉。

## 失败、退出与恢复边界

保存失败可能发生在副作用之后。宿主不补造“工具失败结果”，也不自动重复执行。未完成调用保留开放的 step/turn，另写可忽略的安全失败标记，避免违反原生 JSONL 的配对约束。进程退出时即使来不及写标记，残留调用也会在新宿主中阻止自动恢复。账本和原生日志仍可只读核对。

这是独立宿主的行为变更：其中任何未解决的原生工具调用都不能走原版的自动补造结果恢复。尚无核对后解封的 CLI/UI；不要删除标记或降级宿主绕过它。插件卸载/移除钩子不能撤销已开始调用捕获的保存屏障。补丁应用必须先停止宿主；工具不自动检测或终止运行中的宿主。

## 小批次实测

所有输入、文件和模型回复均为合成数据，运行目录、账本、日志和认证材料在 checkout 外。没有调用真实聊天模型，没有切换日常 profile，没有执行系统睡眠/重启。

原生工具测试通过真实 dsh CLI、标准 preset 和本机二进制；合成 provider 只决定固定调用序列。测试专用 owner-only 插件位于 `plugins/dsh/probes/`，不进入产品 tgz；不接受模型生成的任意脚本或任意外部路径。可复现驱动为 `native-tools-plugin.mjs` / `native-tools-http.mjs`，HTTP 检查经公开 MCP 核对账本，不靠直接读取数据库断言保存成功。

最终 tgz 的 SHA-256 为 `5c3c9618fd9e7f6fd314f55407c4e8812f418b5033dce7f05683df251f1b7335`。运行日志和合成报告留在本机外部目录，认证 URL 不入库。本批默认 npm peer 图仍报告 13 条 high，去重根因为上游 Zod constrained collections 告警；独立宿主及实际 profile 覆盖到 Zod 4.6.7 并分别审计通过。不能用这两个 0 条结果描述默认 peer 安装。

### 复现入口

从 `plugins/dsh` 按 [宿主安装说明](../../plugins/dsh/host/README.md) 新建外部宿主；安装前自动执行发布回归。SDK/Core 用例位于 `plugins/harnesses/test/dsh.test.ts`，`patched tool publication` 四项必须在实际已补丁 rc.5 依赖图运行；仓库默认 rc.3 fixture 只用于旧行为兼容与未补丁拒绝，不能算作 rc.5 发布验证。
