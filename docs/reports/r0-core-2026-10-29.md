输入为预先固定的 94 条合成消息（2021–2026 年证据 14 条、近期无关消息 80 条）、24 条查询（21 条有答案、3 条无答案），含一/两字、专名、数字、长原文、当前/历史、纠错与引用。集合 SHA-256：`562efbaba8432eae054df6cdba330ee13b1d8f276cb972f89c84ab2402fd5c17`。这不是正式的 200 条质量集；仅一组更正，不满足正式质量门槛。源数据和期待标签没有按结果修改。

## 查询质量与耗时

两条路径各有 96 次查询：第 0 轮保存首次 API 结果，后 3 轮暖模型各 24 条共 72 个样本。关闭 embedding 结果缓存；索引与 OS 缓存未清理，无写入/重建并发。MemOS 禁用 LLM 过滤/反思等链路；因此完整请求只包含该配置下 embedding、候选、融合与返回的证据上下文，不含聊天生成、人工解锁或完整产品授权/抑制。

| 指标 | MemOS | 最小路径 |
|---|---:|---:|
| 完整实验请求 p50 / p95 | 9.42 / 12.67 ms | 11.37 / 14.14 ms |
| 仅词法候选路径 p50 / p95 | 0.70 / 1.57 ms | 1.05 / 2.05 ms |
| 至少一个正确来源 Hit@10（21 条有答案查询） | 85.71% | 95.24% |
| 宏平均 Recall@10（按每条期待来源集合） | 78.57% | 95.24% |
| 第一位为期待来源 Hit@1 | 85.71% | 80.95% |
| 3 条无答案查询返回空结果 | 0/3 | 0/3 |

Hit@10 与 Recall@10 定义不同；表中样本小且非独立随机样本，不据此宣称正式 ≥95% 门槛通过。MemOS 在当前/历史、更正、近期定位和精确原话描述上存在漏召回；最小路径有数字长尾漏召回且第一位更差。两者都需要无答案判断；召回候选不等于已经生成错误事实，本轮未测最终回答忠实度。

最小路径另测 query embedding p50/p95 4.54/6.47 ms，融合回源与构造上下文 6.39/8.71 ms。MemOS 的 embedding 与其内部其余环节未单独剥离；词法-only 是公开 query compiler + FTS/pattern repo 候选微基准，不能从完整耗时减去它伪造向量路径成绩。首次 embedding 另有加载成本；不是冷 OS 缓存比较。

重建实测：最小路径约 1012 ms，MemOS 约 721 ms；仅 94 条，不外推百万数据。真实 Python→Node 常驻 stdio 测了 60 次索引请求：启动 255 ms、往返 p50/p95 9.51/18.50 ms；扣除 Node 内部路径的通信/编解码开销约 1.18/2.12 ms。向量预先计算，不包含 embedding；此为可行性成本，不是 Hermes 或未来服务协议验收。

## 离线与抽取候选

运行前设置 Transformers 禁止远程模型，加载已准备的绝对路径；关闭 MemOS telemetry、hub、host fallback 与模型驱动维护。Node fetch 与 socket 被进程内拒绝，完整 embedding、查询、重建及单独抽取探针记录 0 次尝试；缺模型也没有云端回退。

这是**进程级出网禁止验证**，没有关闭操作系统网络，也没有证明 native 库所有网络行为。真正系统断网与目标机测试仍待补验。不能把 MemOS 的 `local_only` 误认为可执行本地抽取：该模式实际关闭 LLM。本轮真实 Qwen 直接调用并经 MemOS 的 `createLlmClientWithProvider`/`completeJson` 适配边界运行；没有验证 MemOS 全部反思/事实沉淀流水线。

给定“合成用户小林最喜欢的饮料是乌龙茶”，期待 `{subject: 小林, drink: 乌龙茶}`：直接调用主体错误为“饮料”，经 MemOS JSON facade 后错误为“乌龙茶”。原始提示与输出均保留；JSON 合法不能算事实正确。该小模型只验证可离线运行，**不建议作为已通过的事实抽取模型**。未达到语义质量准入，不自动启用沉淀。

## 许可、维护成本与建议

发布包 `package.json` 声明 MIT；[固定上游源码的顶层 LICENSE](https://github.com/MemTensor/MemOS/blob/64388b50e2a15528bcdf032e65a1ac792bcf63ee/LICENSE) 是 Apache-2.0，两者差异须在引入/分发前确认。模型基础项目声明 Apache-2.0，转换仓库许可元数据缺失，权重尚不进入发布物。锁文件保存依赖版本和完整性；原生 SQLite 预编译件单独准备，未执行可能触及现有用户目录的 MemOS postinstall。

复用能减少维护成熟的检索、状态、导出与索引维护代码，但带来策略/经验领域适配、dsh 版本兼容、上游行为升级和 Node 原生依赖成本。最小路径较易保持证据契约、桥接开销在此样本较小，但会自己承担所有抽取、时态、更正/抑制、过滤、恢复及质量评测；当前约百行原型不是完整系统成本。

建议优先独立可靠原文账本；MemOS 检索候选保留评估价值，不原样作为唯一证据真相源。候选 embedding 可继续扩展测试；抽取换用更合适模型后重测。语言、模型与平台由 T04 结合 T03 和用户取舍确认。当前只提交实验及证据结论，没有进入 R1、部署、推送或修改 GitHub 票据。
