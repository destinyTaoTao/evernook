# dsh 记忆页面复核：隔离安装验证

在仓库外的合成账本和独立 `evernook-ui35` profile 中，使用 dsh 0.2.1-rc.5、Core 0.1.31 wheel 和插件 preview.35。安装后的 `client.js` 和 `lib/dsh-web.js` 与本次源码构建逐字节哈希一致。原始记录和访问材料留在隔离目录，没有使用用户日用账本或进行模型推理。

真实浏览器中先显示合成画像；另一个已配对身份通过独立服务撤回其合成来源后，页面未手动刷新即移除画像。再显示合成时间线，停止该隔离服务后，页面隐藏原文并显示不可用。只停止本次启动的隔离宿主与服务。宿主沿用隔离 profile 的 provider 配置；其启动日志包含模型提供方相关条目，本次没有向模型提交记忆或发起推理。

组件模拟覆盖视图、来源和历史令牌变化、延迟响应、超过期限、页面隐藏及恢复、来源分页版本冲突、持续变化后停止重试。宿主 CSRF／跨站与生命周期测试、构建、类型检查和包预检通过。真实浏览器中的事实／观察网络、来源及历史弹窗跨客户端变化、服务重启、低速连接、大库和多页面并发尚未完整验收。

前台正常事件循环下约每 3 秒开始复核，12 秒内不能完成则清空；浏览器或系统暂停、线程卡顿、时间调度延迟，以及两次复核之间发生的变更都可能使旧内容暂留。页面回到前台时会清空并重新读取。已交付给宿主或模型的内容不能收回；普通记忆不是全库加密。以上不是即时撤回或日用安全准入承诺。

该版本每个可见投影的复核都会启动 CLI 再访问独立服务。隔离环境中对小型合成时间线连续 5 次 CLI 指纹调用，墙钟中位约 917 ms、最大约 968 ms；不是 p95 或大库结论。多个页面或弹窗的进程、CPU、审计写入和数据库负担尚未量化，需按 #143 优化和评测，不能把此观察作为性能门禁通过。
