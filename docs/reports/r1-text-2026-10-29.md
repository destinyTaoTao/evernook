# T05：普通文本可靠账本

日期：2026-10-29。对应 [Issue #6](https://github.com/destinyTaoTao/evernook/issues/6)，基线提交 `11fb356`。[本地接口](../contracts/python-text-v1.md)是本票据交付边界；没有 HTTP/MCP/dsh 生产适配、保险库、模型和备份启用。备份目的地、启用及恢复验收按用户决定待办。

## 实现与验收映射

| 验收 | 结果与证据 |
|---|---|
| 已授权客户端与版本 | 所有公开读写/状态/握手操作检查 client/token/contract v1；source.entry 绑定该身份。初始化收紧 Windows ACL，重新打开拒绝其他用户读权限；身份错误、版本错误、伪造入口均拒绝 |
| 敏感先分流 | 声明标记、受保护来源和 v1 凭证信号触发整条占位投影，回执明确原件未保存。来源标识的已知信号拒收；合成秘密未落运行文件。仅带密钥 HMAC 留作同源重试校验，密钥独立位于受权限保护的运行目录 |
| 幂等与真实重复 | 12 线程、24 次同来源重试返回同一回执，一条消息/任务；同键异内容或异完成状态冲突，相同文本不同源事件分别保留 |
| 持久化与故障 | 原文与待处理任务在 SQLite WAL/FULL 的短事务内提交；实际写锁和 SQLite 页配额 `SQLITE_FULL` 均失败、不留消息/任务。子进程在 COMMIT 前 `os._exit` 后无记录；成功回执后 `os._exit`，重新打开逐字恢复并重试同回执 |
| 原文与来源 | 中文、标点、数字、CRLF、emoji、组合字符不归一化；源序号、时间偏移、角色和完成状态往返一致。源时间未知保持 None；同时间按来源/源序号分页；非法编码、无偏移时间、非法事件和超限文本明确拒绝 |
| 配置与运行隔离 | 严格配置/凭证版本和字段/类型，重复 JSON 键拒绝；数据与访问材料在 checkout 外，目录重定位、相对路径和 checkout 内运行目录拒绝。核心没有请求日志或网络/模型调用 |

## 实测环境与命令

- 当前 Windows/i7-10700/约 32GB、固定 NTFS；Python `3.14.4`、SQLite `3.50.4`，记录在外部 `environment.txt`。没有目标 GPU/大数据规模性能结论。
- 新建独立外部虚拟环境，以 `uv pip install -e ".[dev]"` 实际安装成功；运行时标准库，开发检查 mypy `1.18.2`。
- 完整核心回归：`python -m unittest discover -s tests/contracts -v`，最终 12 项通过（61.949 秒，包含反复启动 ACL 检查及子进程，见 `tests-final.txt`）；类型检查：`python -m mypy`，严格检查 9 个源码/测试文件通过。耗时不是服务延迟基准。
- 外部原始检查输出：`E:\evernook-lab\r1-text-20261029`。测试库在 checkout 外的独立临时目录，只有合成数据，结束后清理；没有初始化日常 `E:\EverNookData`。

## 验证边界

页配额验证实际 SQLite FULL 分支，不是填满物理磁盘。进程退出不是断电或硬盘故障；WAL/FULL 不能替代独立备份。未测试 RPO/RTO、日常长期运行或全盘灾难恢复。ACL 防止普通其他账户直接读文件，不隔离同账户、管理员或已被控制的宿主。凭证检测是有限信号集，不保证所有语义、编码、跨片段秘密都可识别；显示前安全分类和恢复回放仍由 T10 验收。

任务仅已可靠登记，尚无后台消费者。分页是当前视图，不提供并发新增时的固定快照。原始事件不可覆盖；后续更正、重要记忆、附件、检索与模型能力不属于本票据。GitHub 票据没有关闭、评论或修改；没有推送。
