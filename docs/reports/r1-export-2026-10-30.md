# T09 增量：普通导出与受审查限制的恢复

日期：2026-10-30，对应 [Issue #10](https://github.com/destinyTaoTao/evernook/issues/10)，代码基线 `bc74a0e`。用户明确选择本轮只实现普通导出、完整性校验与受审查限制的恢复，备份继续待办。[归档契约](../contracts/archive-v1.md)给出接口、权限和恢复边界；本增量不关闭整张 T09，不解除 T10 的相关依赖。

## 实际交付

| 范围 | 实现及验证边界 |
|---|---|
| 一致性普通导出 | 已授权且具 archive_review 的客户端通过同一核心入口导出；使用 SQLite Backup API、私有暂存、文件同步、完整性校验与目录发布，不直接复制活动主库 |
| 证据保留 | 普通原文/安全投影、稳定来源和回执、重要交代、显式更正/抑制、工具/附件清单与内容保留；当前 schema v4 的派生索引和待处理任务随快照保留，仍不运行消费者 |
| 清单和损坏检查 | 固定格式/版本、归档 ID/创建时间、数据库 SHA-256 与数量；检查数据库结构/外键、附件尺寸和哈希，拒绝未知格式、错误类型、侧文件、额外文件及目录外引用 |
| 新目录受控恢复 | 验证后复制并重新校验，完整目录才发布；同一归档同一目标幂等，不覆盖其他归档；发布前进程退出后可向原目标重试 |
| 原文审查 | EvidenceArchive 只提供 review_*，原文、重要交代和工具清单带快照状态及 archive_only；附件只通过显式审查读取 |
| 失效状态边界 | 不生成运行时身份或密钥，不提供 read/search/submit，不开放普通召回；不能证明快照后更正/抑制/删除完整时，一律 review_required |
| 安全分流 | 只导出普通库现存表示；未保存的受保护原件仍缺失；包中不复制访问令牌、配置、幂等密钥或保险库材料，普通导出明确未加密 |

## 环境与验证

当前 Windows 11 x64 / Python `3.14.4` / SQLite `3.50.4`；沿用仓库外 MCP 虚拟环境，核心未增加依赖。所有数据库、令牌及归档使用仓库外合成临时数据，没有初始化日常运行库、安装宿主插件、注册计划任务或启用备份。

`python -m unittest discover -s tests/contracts -v` 完整 74 项通过，527.502 秒，含既有 66 项和初始归档 8 项（`tests-final.txt`）。完整检查运行期间的资源/格式增量另以归档 8 项复验通过，138.320 秒（`tests-archive-final.txt`）；随后新增明确快照超时的外部回归，先红后绿，1 项通过、3.326 秒（`tests-timeout-final.txt`）。因此当前 75 个契约用例均有通过证据，不宣称对最终源码额外重跑过一轮完整 75 项。严格 `python -m mypy` 检查 21 文件通过（`types-final.txt`），暂存差异检查与新增文档相对链接检查通过。

耗时包含 Windows ACL、真实子进程和同期测试，不代表服务或导出延迟基准。原始输出保存在 `E:\evernook-lab\r1-export-20261030`；过程失败已修复并记录在本地计划中，没有把失败轮次混成最终通过结果。

## 对抗式自审

自审针对归档越权、秘密材料复制、旧快照复活、附件损坏、活动 WAL、发布中断、目标覆盖、格式类型和资源边界展开。发现并修正：SQLite URI 连接参数遗漏；篡改测试未关闭连接导致 WAL 未归并；归档需要拒绝活动侧文件；快照超时应与 storage_busy 区分；清单/数据单条读取需要资源上限。实现未扩展普通 MCP 的权限或工具集合。

这是主代理自审，不声明独立 Standards/Spec 复审通过。自审未发现剩余确认缺陷；测试只覆盖已确认的本地归档边界。

## 继续待办
