# 百万条召回关键词 BM25 阶段实测

本次优化先按 BM25 和消息 ID 选出一批 FTS 行，再校验来源。百万条夹具的近期、历史查询中，需要查源表的 FTS 行数从 999,999 条降至最多 256 条。公开召回接口每类查询各进行四轮对照，每轮的关键词候选顺序和完整召回页一致。

## 瓶颈定位

在 SQLite 只读事务上，用近期查询对应的关键词条件分别执行各个 SQL 变体。该查询的 CJK 二元词组「合成」「成条」「条目」通过 OR 匹配，命中 999,999 行。下表各行是独立整句的墙钟和 CPU 时间，单位秒。

| SQL 变体 | 墙钟 | CPU | 结果与计划 |
| --- | ---: | ---: | --- |
| 纯 FTS 匹配计数 | 0.072 | 0.062 | 命中 999,999 行 |
| 纯 FTS 逐行计算 BM25，汇总数量和分数 | 0.688 | 0.672 | 计算 999,999 个分数 |
| 纯 FTS 计算 BM25、按消息去重并排序 | 3.991 | 3.969 | 返回前 100 条，使用分组和排序临时 B-tree |
| FTS 匹配后逐行应用来源约束，结果计数 | 24.641 | 24.203 | 校验后仍有 999,999 行，计划含额外的 visibility LEFT JOIN |
| 完整来源校验和 BM25，汇总数量和分数 | 22.147 | 21.516 | 与基线相同的内层连接计划 |
| 完整基线排名 SQL | 23.466 | 23.141 | 来源校验后去重和排序，返回前 100 条 |
| 只按 BM25 和消息 ID 取 FTS 前缀 | 2.274 | 2.234 | 排序后留下 256 行 |
| FTS 前缀连接来源并去重 | 2.491 | 2.484 | 校验至多 256 行后返回 100 条 |

基线计划从 FTS 扫描开始，对命中逐行访问 `lexical_docs` 和 `messages` 的索引，再检查可见性、生成证据和内容版本。去掉最后的分组和排序后，保留这些连接的 SQL 仍耗时约 22 秒。纯 FTS 计算全部 BM25 约 0.7 秒。结合查询计划，主要成本落在对大量匹配记录反复应用源记录约束。计数变体保留了额外的可见性连接，表中耗时受执行计划、物化方式和缓存影响，按整句比较。

这 999,999 个匹配分为 17 个 BM25 分值。最优四个分值分别有 1、8、32、75 条，前 100 名的边界位于第四个同分组内。候选实现使用 SQLite 的文本消息 ID 和 `BINARY` 排序稳定处理同分。对每个消息，按分值和 ID 顺序遇到的第一条 FTS 记录给出最佳分值。若前缀已取尽全部 FTS 匹配，或已得到 100 个合格且不同的消息 ID，前缀足以提供完整结果。填满前缀且不足 100 条时，回退到完整排名 SQL。原文、现行版本、可见性、反思工具生成证据排除、当前输入 ID 排除和时间范围约束在同一读快照内执行。

## 冻结源码 A/B

基线为 `86a18f4`，候选与基线的 Python/JavaScript 包源码只在 `semantic.py` 上有差异。测量环境为 Windows、Python 3.14、SQLite 3.50.4。保留系统默认缓存，用两个独立进程依次调用公开 Python API `SemanticRecall.recall`。共用同一份外部 SQLite 备份，索引已启用，包含 100 万条合成来源与 384 维合成指纹。合成指纹替代模型推理。固定 `as_of=2026-11-04T00:00:00Z`、`limit=10` 和 `timeout=120` 秒。两条查询的编号不同，关键词提取使用相同的三个 CJK 二元词组，字面精确与语义渠道仍按各自的完整查询运行。查询按轮轮换，每种查询的每个实现各先跑两次。p95 取最近秩，四轮样本中为最大值。以下耗时均为秒。

交付代码在冻结候选之后增加了异常回退。当试探性前缀查询报告 `SQLITE_CORRUPT_VTAB` 且读事务仍在时，改走原完整排名。这一异常分支未触发于正式测量，正常路径的 SQL 和排序规则与冻结候选相同。

公开调用带审计写入。使用 SQLite `dbstat` 对比原始备份和测量文件，审计序列增加 384，共 24 页发生变化。变化限于审计 B-tree、`sqlite_sequence` 和 SQLite 首页。模式、非审计序列和其余 1,456,052 页逐字节一致。

结果范围为两条固定合成查询和一台 Windows 设备上的本地 SDK 调用。前缀只减少来源校验工作，FTS 仍计算全部匹配的分数。需要回退时会在完整排名前额外计算前缀。端到端样本 p95 仍高于 1 秒。
