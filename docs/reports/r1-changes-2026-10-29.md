# T07：显式更正与不再召回

日期：2026-10-29。对应 [Issue #8](https://github.com/destinyTaoTao/evernook/issues/8)，基线 `03721b4`。[变更契约](../contracts/changes-v1.md)沿用统一本地 Python 边界，不改写原始证据或人格。

## 验收与证据

- 显式变更引用完整用户原文，保存变更来源、原因与时间；原始消息不覆盖。目标不存在、证据缺失/自身/投影/助手/未完成、非法请求拒绝。状态版本 CAS，两个并发旧版本请求只确认一个；完整请求幂等，旧重试不能覆盖新确认。
- 更正、撤销、抑制通过持久化可见性统一影响 ID/来源/时间读取、重要标记/回取和派生上下文。归档记录仍存在；独立 `archive_review` 服务器授权默认关闭，旧身份文件不自动增加权限。归档接口返回明确 archive_only 类型与变更历史。
- 最小派生发布接口在事务内核对来源版本与可用状态，读侧再次核验。已有结果被抑制后不可读；真实挂起的合成工作线程在主线程确认抑制后发布会拒绝，重启/旧任务重试同样不能复活。没有启动真实后台消费者、模型或全文索引。
- 实际 SQLite 页配额触发 FULL 后，状态/变更历史保持最后确认版本，失败请求可安全重试；真实子进程在变更 COMMIT 前退出回滚，回执后退出保留抑制与幂等回执。仍保留普通原文与重要引用的故障回归。
- 存储 v1/v2 兼容补表至 v3；新身份 schema v2、旧 v1 普通权限兼容。各新增公开操作复用认证；显式/检测敏感的派生结果拒绝，投影来源不能发布其他文字。
