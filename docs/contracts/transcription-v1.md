# 语音转写材料 v1

对应 #168、#124。识别、合成、音频设备和模型选择由宿主或独立适配器负责；记忆服务不接收音频、不调用识别模型，也不会根据配置自动连接云端。宿主必须在录音、第三方识别和首次转录前完成授权与私密分流；本接口不能补救宿主已经发送或记录的内容。

可信宿主传入 `Transcription(source, sequence, occurred_at, completion, text, provider, model, language, execution, start_ms, end_ms, confidence=None, sensitive=False, speaker='unknown')`。来源沿用现有 entry/session/branch/event 及已配对 capture 权限；时段是相对录音的毫秒偏移，最长 24 小时，发生时间使用既有带时区时间规则。`execution` 只能为 `local` 或 `remote`，它是宿主报告的事实，不授予联网许可；`provider`、`model`、`language` 是不含 URL、本机路径或凭证的有界标识，模型标识可采用 `provider/model` 格式。不能仅凭格式检测证明标识不含秘密，宿主仍须负责。`speaker` 是宿主报告的 `user`、`assistant` 或 `unknown`，不能证明说话人身份。可选 confidence 必须为 0..1 的有限数，不等于经过校准的正确率。不能通过该接口声明本人已确认；确认应由用户另行产生真实证据，不能由识别模型或布尔参数自授。

已完成的普通转写将原文逐字作为来源绑定的 `tool` 消息保存，ASR 元数据保存在同一 capture 事务的 JSON 附件；回执含原文和附件的保存状态。检索、语义召回、主题引用与预算上下文标记 `asr_transcription` 和 `confirmation=unverified`，不将其作为独立用户陈述自动沉淀。元数据丢失或损坏时显式返回未确认、不可用标记；无法判断原类型的无 capture 工具记录标为来源元数据不可用。标记是证据属性，不证明模型准确，也不授予权限。普通文本和转写均未做全库静态加密。

实验性反思沿用既有证据范围、远程授权、超时与费用门禁；模型端作为转写元数据只获得类型、未确认状态、宿主报告的说话人和可选置信度，不附带 ASR 提供方、模型名或录音偏移；转写正文自身仍可能包含任何用户说过的信息。选择远程 ASR 的实际授权仍由宿主负责，记忆服务不据 `execution=remote` 发起调用。来源或元数据在模型交付前变化时，相关上下文和证据失效。

明确标私密或命中现有凭证检测时，必须配置服务绑定的保险库；完整原文和模型、语言、时间及置信度元数据一起封装为版本化 JSON 后加密保存，普通账本只留投影和引用，普通搜索、转写读取与上下文不返回明文。来源标识、记录时间等路由元数据仍可能可见，宿主不得把秘密放入这些字段。单次本机保险库窗口显示该 JSON，调用方仍须自行按字段理解内容。未绑定保险库时拒绝，绝不明文回退。不完整的普通转写只保存受保护投影及缺口，不声称保存原文；不完整私密转写拒绝提交。独立保险库备份和完整私密会话仍受 #115/#117 限制。

`ServiceClient.submit_transcription(access, material)` / `read_transcription(access, message_id)` 提供 Python SDK；可信 CLI 使用 `service-transcription-submit --config ... --access ...`，材料 JSON 通过 UTF-8 stdin 输入，读取使用 `service-transcription-read --config ... --access ... --message-id ...`。服务分别提供 `transcription-submit` / `transcription-read`，使用既有认证加密帧；即使普通转写也要求安装 vault extra 的 PyNaCl，缺依赖或旧服务时拒绝，不能回退明文。接口不注册 MCP 模型工具，也不让模型选择提供方、授予权限或执行动作。

可信 TypeScript 宿主可从 `@evernook/harnesses/transcription` 导入 `TranscriptionClient`，使用绝对路径配置 `{python, config, access, cwd?}`，调用 `submit(material, signal?)` 和 `read(messageId, signal?)`。它固定启动上述 CLI，经 stdin 传材料、忽略 stderr，并始终要求独立服务；材料不会作为进程参数或模型工具参数。响应上限 8 MiB、等待上限 30 秒；预先取消不启动进程，运行中取消或超时不能证明服务未提交，必须以完全相同来源和材料重试核对。客户端不收集音频，也不负责宿主录音和远程识别授权。

#183 源码及安装版合成集成各通过真实隔离服务：普通提交和幂等回读、未配置保险库拒绝、私密提交与普通读取隔离、来源撤回、预先取消；安装版另验证无客户端加密依赖及服务离线时拒绝，普通数据库不含合成私密正文。TypeScript 类型检查和构建通过；未验证真实语音模型、运行中取消的竞态或日用准入。

相同来源与材料重试返回同一回执；来源相同而正文、质量或其他材料变化时返回冲突。SDK 可限制等待时间或取消等待；中断并不证明服务未提交，须以相同来源和完全相同材料重试获取回执。用户实际核对后的独立用户证据可通过既有 `Change(correct)` 与原转写建立替代关系，原转写退出普通召回，替代文本作为独立用户证据；没有隐式批量确认。普通来源的更正/抑制/删除遵循现有版本、撤回和防复活规则；普通归档保留转写与元数据供审查，但不保存保险库密文或恢复材料。返回前核对来源和元数据，已交付给宿主或模型的内容无法撤回。此增量不包含音频原件、分片实时语音、对齐到单词的时间戳、识别质量/资源门禁或对已有 ASR 输出的追溯重标；不代表语音模型或整个系统已获日用准入。

Core 0.1.45 的合成验证覆盖精确回读、幂等冲突、受限身份、来源撤回与替代、物理删除防复活、审查归档及已知撤回重放、元数据缺失/损坏和交付前变化。独立安装版通过真实子进程服务、Python SDK、CLI 的普通与私密路径；私密测试解密合成保险库验证封装，检查请求加密帧、无加密依赖和无保险库时不明文回退，并扫描隔离运行文件。模拟远程提供方只接收获准的合成证据与最小转写标记，未获得合成保险库正文或 ASR 模型标识；未访问真实云服务或用户记忆。源码受影响回归 123 项、后续定向 49 项、安装版 17 项和 strict mypy 通过。早期远程集成测试因旧夹具未激活独立服务失败，更新启动参数后复测；冻结评测集、评分与提示模板未修改。由于本机验收只覆盖合成输入，不声称真实 ASR 质量、全场景并发或日用准入。
