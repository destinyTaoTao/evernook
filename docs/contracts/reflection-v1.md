# Experimental reflection v1

#120 provides explicit temporary memory exploration inside the independent service. Normal context/recall does not invoke a chat model. Local Qwen3-0.6B is experimental for this purpose; protocol/function tests do not admit its reasoning quality.

Trusted startup `evernook.service --config ... --reflection-config ...` selects one local profile. A trusted `reflect-configure` CLI/service call requires maintain+accept and installs the existing optional topic evidence/control/derived clocks atomically. Reflection queries require recall only; they cannot install schema, change policy or select paths. Omit the startup flag to disable the tool. No cloud provider or model downloader is used.

External profile shape:

```json
{"schema_version":1,"profile":"qwen3-0.6b-experimental-reflection-v1","node":"C:/local/node.exe","transformers_dir":"C:/local/node_modules/@huggingface/transformers","model_dir":"C:/local/models/qwen3-0.6b","policy":{}}
```

The fixed extraction asset hashes, transformers4.2.0/ORT1.24.3 identity and new worker bytes are checked. The worker counts the complete untruncated chat template before generation and meters actual generated IDs, including EOS. Each invocation is capped at4096 input/512 generated tokens; the total request input/output quotas are independent. Worker failure before a usable meter is explicitly `usage.metering_incomplete`, not an assumed zero-cost success. Cancellation/timeout kills and reaps the owned Node process. OS isolation against malicious code of the same account is not provided.

`ReflectionPolicy` has normal/deep `ReflectionBudget`s. Defaults (normal/deep): seconds20/60, search rounds1/4, model rounds1/4, tool calls2/8, candidates10/32, source spans8/16, source characters4096/8192, total input tokens4096/8192, output tokens256/1024. Policy JSON may replace either complete budget object and set concurrency1–2 (default1), cache_entries0–32 (default0), cache_ttl1–300 seconds (default30). Values are validated against hard maxima. Caller timeout can only reduce the chosen budget. A small part of wall time is reserved for final validation; if it expires, no evidence body is returned. Concurrency is enforced by the service-owned engine for the whole ledger.

`reflect(query, mode='deep', topic_view_ids=(), timeout=None, current_input_id=None)` is exposed through trusted CLI `reflect` and read-only MCP `evernook_v1_reflect`. Model actions are a strict finite schema: search(short query), read(discovered message ID/start/chars), navigation(discovered source session neighbours), view(caller-allowed view ID), done(conclusions/conflicts/unknown/clarification). They never reach a generic dispatcher, shell, network, maintenance, persona or vault tool. Original search runs before a model may conclude unknown. Sensitive query signals are checked on the entire original input before vectorization/model invocation; model-produced searches have the same guard. Natural-language secrets require the explicit private input boundary tracked in#115.

Sources include exact Unicode spans, current state/content versions, role, occurred/learned times and origin. Current input is excluded by receipt ID. Topic conclusions are not promoted to independent evidence; their current original citations are reread. Each model turn and final handoff check identity, source spans, selected view heads and global clocks. Changes clear *all* model text, including unknown explanations; diagnostic search queries expose only hashes/lengths. Verified remaining original evidence may be returned with degradation. Authorization is checked again at delivery. Cache, if explicitly enabled, is only process memory and binds actor/input/current input/mode/selected views/installed processor/policy/clocks; every hit still verifies sources and view heads. No durable result cache is created.

Output is `untrusted_memory_reflection`, evidence plus conclusions marked `inference=true, verification=unverified_model_inference`, conflict sets, unknown/clarification, coverage, stop_reason and separate counters. A valid ID/quote does not prove semantic entailment. `state=complete` means the model finished a valid protocol action, not that memory coverage or its conclusion is correct. Budget, invalid model output and failures return partial evidence with no model claims. dsh owns final conversation and external actions.

No fact/profile/persona/observation is automatically written. dsh still retains raw tool auditing as required by the raw-log contract. Structured `tool_result` captures named `evernook_memory_reflect` are excluded before ordinary recall candidate limits, vector maintenance, related semantic channels, topic/observation evidence validation and internal navigation. They remain explicitly readable/searchable as raw audit records, and do not become independent evidence in a later reflection. This exclusion cannot identify arbitrary assistant paraphrases or externally relabelled copies; assistant/tool role attribution still never counts as independent user support.

dsh native/Web option `reflection` defaults false and only exposes the explicit deep tool. Its current input receipt is passed to Core. Tool transport timeout includes service execution and validation overhead. The Web character compatibility and durable publication gates remain unchanged; durable_text deliberately refuses tool execution, while buffered/fixed-patch durable_tools use existing capture barriers.

Rollback: disable the dsh option and service startup profile. Ordinary memory continues independently; installed clock/control schema remains so existing view freshness is preserved. No dependency upgrade, data rewrite or inference admission is implied. User-requested long-term consolidation of a result must go through the separate candidate/risk workflow; this version offers no automatic result-promotion shortcut.

## Core0.1.21 local-model protocol v2

The public reflect/MCP/dsh interfaces and existing Core action protocol remain compatible. The pinned local model now receives a smaller packet with current question, actual evidence IDs/quotes/roles, statement time labelled separately from event time and discovered source IDs. Learned-at/index/runtime metadata is omitted from model input but remains in returned original evidence. Independent synthetic demonstrations are not part of the current evidence map and cannot be cited. The old filled answer/`e1` placeholder is removed.

The local wire has `answer(value,support)`, `abstain(support)`, `clarify(support)` and `refuse(support)`, plus the existing read-only exploration actions. Support maps actual evidence IDs to exact nonempty substrings of the supplied original quote. Unknown IDs, fabricated/rewritten quotes, invalid JSON, duplicate JSON keys, unexpected fields or write/external actions are rejected. The adapter never fills a missing ID, edits a quote or repairs malformed JSON. A validation failure may request fresh model generation using a fixed reason enum, consuming the existing model-round, input/output and wall-clock quotas; no new tool or retry budget is granted.

The worker suppresses premature EOS and stops when the generated text itself parses as one whole JSON object, or when the unchanged hard token/time budget stops it. No closing characters are added after decoding. Python's strict unique-key parser and action/source validators still run; a syntactically complete object is not an accepted action. The stopping helper and protocol source bytes participate in the pinned processor identity and pre-worker integrity check.

Core independently rechecks optional claim support against the actual current evidence, rebases it to original absolute code-point spans/versions, and validates the optional `assessment` decision with its reason citations. This preserves references for real abstention/refusal instead of guessing them from all retrieved candidates. Legacy backends without these optional fields remain unverified inference. All failure/revocation/cache checks also cover assessment and proof text; failed handoff clears them.

For direct first-person user preference clauses only, the existing finite preference parser can detect a contradiction in a referenced slot. A one-sided local answer is then replaced with clarification and both original sides, explicitly labelled `assessment.origin=finite_preference_guard`; this is not reported as model understanding. Quoted, assistant/tool, temporary and otherwise ineligible statements do not become independent user conflicts. An explicit four-digit year/ISO date (or a bare four-digit answer) absent from all support quotes is conservatively withheld with `assessment.origin=explicit_year_guard`; statement metadata cannot supply that event year. This deliberately does not perform relative-calendar inference and is not evidence of model understanding. General semantic contradiction and entailment remain unverified, and exact quote matching never changes `unverified_model_inference` to a truth certificate.

The frozen collector projects actual assessments and reason citations only, preserves fallback abstention separately and records finite-guard origin. Synthetic-only worker envelopes may be retained in external diagnostics, deduplicated by worker PID; production does not log generations. The suite, scorer and admission policy are unchanged. New model identity does not inherit admission; the feature stays disabled by default.
